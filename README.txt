lumi叫你背单词 · iPhone 离线主屏幕版

这个公开仓库仅包含背词网页、离线词库和图标。学习进度和导入的词表仅保存在使用者当前设备。

手机使用：
1. 用 iPhone Safari 打开 GitHub Pages 网站链接。
2. 等页面完整加载后，点分享 → 添加到主屏幕 → 添加。
3. 从主屏幕图标联网打开一次，再切飞行模式检查离线访问和发音。

词库默认 B1 及以上，可在设置中提高到 B2 / C1 / C2。
学习记录保存在当前设备，可在设置里导出备份。
英文朗读使用设备语音；离线发音需要设备上已有英语语音。


v1.2 更新
